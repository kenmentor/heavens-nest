## ADDED Requirements

### Requirement: Admin overview of users
The system SHALL provide a basic admin area that displays all registered users in a table with their role, and shows summary statistics of the platform (total users, total listings, total enquiries).

#### Scenario: Admin area loads
- **WHEN** an administrator opens the admin area
- **THEN** they see platform summary statistics and a table of all registered users with their roles

#### Scenario: Admin sees all records
- **WHEN** an administrator views the admin area
- **THEN** they can see users, listings, and enquiries across the platform (oversight view)
